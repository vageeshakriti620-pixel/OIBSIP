# OIBSIP — Data Analytics Internship Projects

This repository contains the projects completed as part of my **Data Analytics Internship at Oasis Infobyte (OIBSIP)**.

## 📊 Projects

### 1. Retail Sales Exploratory Data Analysis

**File:** `EDA_Retail_Sales.ipynb`

This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales patterns, customer behaviour, and business insights.

**Key Activities:**
- Dataset inspection and data quality analysis
- Descriptive statistics
- Monthly and quarterly sales analysis
- Customer age and gender analysis
- Product and category performance analysis
- Top-selling products identification
- Correlation analysis
- Additional sales visualizations
- Business insights and recommendations

**Tools Used:**
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

### 2. Customer Segmentation Analysis

**File:** `Customer_Segmentation_Analysis.ipynb`

This project segments e-commerce customers based on their purchasing behaviour using **RFM analysis and K-Means clustering**.

**Key Activities:**
- Dataset inspection and data cleaning
- Handling missing and inconsistent data
- Customer-level RFM analysis
- Recency, Frequency, and Monetary feature creation
- Feature standardization using StandardScaler
- Elbow Method for selecting the number of clusters
- K-Means clustering
- Customer segment visualization
- Cluster profiling
- Customer distribution analysis
- Marketing recommendations for each segment

**Tools Used:**
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
